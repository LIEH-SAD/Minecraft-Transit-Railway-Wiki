# 第一章：安装和配置MTR模组
首先，我们需要安装MTR模组，它需要1.16.5-1.21.4的Minecraft版本和Fabric/(Neo)Forge模组加载器。
对于安装游戏和模组加载器，我们以官方启动器、Minecraft1.20.1、Fabric模组加载器为例。
## 1.打开启动器，下载版本
（注：Java的下载不介绍，推荐安装Java21）
我们先打开开始菜单里的 **Minecraft Launch** ，在启动器的左侧选择 **MINECRAFT: JAVA EDITION** 按钮进入Java版选项。
然后，找到 **配置** 选项，在下方按钮 **新配置** 中，选择1.16.5 、1.17.1、1.18.2、1.19.2(推荐)、1.19.4、1.20.1(推荐)、1.20.4、1.21.1、1.21.4里面任意一个Release（正式）版本，名字请自定义一个英文名，目录找一个你知道的目录，后面要考。
![选项](https://free.picui.cn/free/2026/07/24/6a636c59bc23f.png)

我们以1.20.1版本为例，选择 **安装** ，等待安装完成。
## 2.安装模组加载器
（注：对于非官方启动器，也可以先下载版本，安装教程安装加载器）
安装完成以后，打开你刚才选择的安装目录。
打开这个链接：[$|$](url)https://fabricmc.net/use/installer/ 选择Download（下载）
下载后打开，选择你安装的游戏版本，找到刚才的目录，勾选 **创造新的启动器配置**，选择安装。
安装结束后，在启动器找到新的配置，并且启动，正常加载主界面后，退出游戏。
## 3.下载Fabric API和模组
你看到主界面什么都没有，这是因为没有安装Fabric API和模组菜单等，Java版很多模组插件需要自己安装，或者使用资源包。
打开Modrinth，我们来下载Fabric API和MTR本体，下面推荐了你可能需要的模组和下载链接。

| 模组名称 | Modrinth 下载链接 | CurseForge 下载链接 |
| :--- | :--- | :--- |
|  Fabric API | https://modrinth.com/mod/fabric-api | https://www.curseforge.com/minecraft/mc-mods/fabric-api |
|  我的世界铁路 (Minecraft Transit Railway) | https://modrinth.com/mod/minecraft-transit-railway | https://www.curseforge.com/minecraft/mc-mods/minecraft-transit-railway |
|  创世神 (WorldEdit) | https://modrinth.com/plugin/worldedit | https://www.curseforge.com/minecraft/mc-mods/worldedit |
|  模组菜单 (Mod Menu) | https://modrinth.com/mod/modmenu | https://www.curseforge.com/minecraft/mc-mods/modmenu |
|  轻松建造 (Effortless Building) | https://modrinth.com/mod/effortless-building | https://www.curseforge.com/minecraft/mc-mods/effortless-building |
选择对应的版本和加载器后，把它们拖入到安装目录的mods文件夹，然后打开游戏，不出意外的化，你可以游玩它们了。
