# 附属模组：**Nanbin Create Mod** 的使用
欸嘿！接下来由模组的开发者——**LIEH-SAD**亲自为您讲解吧。
（这多少有点中二病）
作为一个不太正经的MTR附属模组，Nanbin Create Mod（以下简称NCM）更是一个偏城建的模组。
NCM 主要想要还原西南四省和广西省部分城市的城市建设和铁路设施，目前开启了蓉（部分）、渝、桂（部分）
对了，NCM的规划蓝图中，在3.0以后版本仅开发 MTR4.0.0 和 4.1.0 的扩展，偏向于1.20.1及1.21.1的开发。
## 闸机的使用
首先，你需要在有关闸机的标签页中找到闸机，如：**CRT入站闸机（璧山站）** 等。它们的使用和原版相似，但是闸机自带侧机，不需要像Joban一样用侧机覆盖。
对于提示带有：**颜色取决于车站** 的闸机，一般有色块会读取你设置的车站颜色，修改颜色只需要在 **铁路仪表盘** 中设置车站颜色即可。
对于栏杆的兼容，可以使用模组的 **适合闸机的CRT栏杆** 或者使用原版栏杆及其他适配了闸机的栏杆都不会穿模。

## 来点栏杆
栏杆在NCM中随处可见，其使用方法为右键放置，其中 **CRT临时栏杆** 采用的原版栏杆放置的逻辑，不详细介绍。
## 总结
Nanbin Create Mod 虽然提供了很多方块，但缺少创新性，而且大规模使用Yarn映射，不利于多平台开发，但是目前模组日渐成熟，希望可以在未来加入更稳定、更有意思的玩法。
