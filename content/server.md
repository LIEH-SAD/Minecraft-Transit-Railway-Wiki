# 加入Let's Play 服务器
一个人玩一个存档是无聊的，为何不加入Let's Play服务器呢？
首先，我们要下载服务器的整合包：
https://1drv.ms/f/c/959219da68d47a00/Eovu-Le5Y9JFtEgGSX10AwcBuAc7051FoGz_K9jf-qMHNA?e=p5DI3S
打开 PCL2 ，把下载的zip文件拖进去安装。
（确保你已经登录微软账户）
然后，启动它，在多人游戏里面添加服务器：

| 服务器链接 | 备注 |
| --- | --- |
| 默认地址 | 要开梯子 |
| mc.lnlfly.com | （感谢 MZDYHR 搭建）国内可访问 |
